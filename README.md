# 다운로드 · 바탕화면 정리 (Windows)

중복 파일과 오래된 동영상을 찾아 **휴지통**으로 보내고, 남은 파일을 종류별 폴더(문서, 이미지, 동영상, 음악, 압축파일, 설치파일, 기타)로 정리합니다.

## 사용법

1. 이 폴더(`pc-cleanup.ps1`, `1_미리보기.bat`, `2_실행.bat`)를 PC에 내려받습니다.
2. **`1_미리보기.bat`** 을 더블클릭합니다.
   - 아무 파일도 바꾸지 않고, 바탕화면에 `PC정리_보고서_날짜` 폴더와 `정리_목록.csv` 를 만들어 엑셀로 엽니다.
3. 목록을 확인하고, **남기고 싶은 파일의 줄은 삭제**한 뒤 저장합니다.
4. **`2_실행.bat`** 을 더블클릭하고 `Y` 를 입력합니다.
   - 가장 최근 목록에 남아 있는 파일만 처리합니다.
   - 삭제는 모두 휴지통으로 가므로 되살릴 수 있습니다. 옮긴 파일은 `이동_기록.csv` 에 남습니다.

## 기준

| 항목 | 기준 |
|---|---|
| 중복 파일 | 내용이 완전히 같은 파일(SHA-256). `(1)`, `복사본`이 없는 이름 → 짧은 이름 → 먼저 만든 파일을 남김 |
| 동영상 | 마지막 수정 후 **180일** 넘은 동영상 (mp4, mkv, avi, mov 등) |
| 폴더 정리 | 다운로드/바탕화면 맨 위에 있는 파일만 이동. 이미 만든 하위 폴더, 바로가기(.lnk, .url), 숨김·시스템 파일은 건드리지 않음 |

기준을 바꾸려면 PowerShell에서 직접 실행합니다.

```powershell
# 30일 넘고 500MB 이상인 동영상만
powershell -ExecutionPolicy Bypass -File .\pc-cleanup.ps1 -Organize -VideoOlderThanDays 30 -VideoMinSizeMB 500

# 동영상은 건너뛰고 중복만
powershell -ExecutionPolicy Bypass -File .\pc-cleanup.ps1 -SkipVideos
```
